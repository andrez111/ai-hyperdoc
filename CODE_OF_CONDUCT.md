# Code of Conduct

This project is intended to support clear technical collaboration.

Participants are expected to:

- discuss ideas and behavior rather than attack people;
- provide reproducible examples when reporting problems;
- accept disagreement without hostility;
- avoid harassment, discrimination, threats, or deliberately disruptive behavior;
- respect privacy and avoid publishing private conversation content without permission.

Project maintainers may edit, hide, reject, or remove contributions that materially violate these expectations.

If a conduct issue requires private handling, contact the repository owner through the private contact method listed on their GitHub profile rather than opening a public issue containing personal information.
